---
title: "Requirements"
description: "WordPress, PHP and database versions SpaceBay needs, and what SpaceBay Pro needs on top."
---

| Item | Minimum |
| --- | --- |
| WordPress | 6.2 (tested up to 7.1) |
| PHP | 7.4 (tested up to 8.4) |
| MySQL / MariaDB | 5.7 / 10.4 |
| Permalinks | Any. Pretty permalinks give the community its own address such as /community/. |

SpaceBay Pro is an add-on. It needs the free SpaceBay plugin installed and active, and WordPress 6.5 or newer.

See [Compatibility](/spacebay/others/compatibility/) for the themes, plugins and languages SpaceBay was tested with.

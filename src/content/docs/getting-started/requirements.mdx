---
title: "Requirements"
description: "WordPress, PHP and database versions SpaceBay needs, and what SpaceBay Pro needs on top."
---

| Item | SpaceBay (free) 1.0.0 | SpaceBay Pro 1.0.0 <span class="sb-badge sb-badge--pro">Pro</span> |
| --- | --- | --- |
| WordPress | 6.2 or newer (tested up to 7.1) | 6.5 or newer (tested up to 7.1) |
| PHP | 7.4 or newer (tested up to 8.4) | 7.4 or newer |
| Other plugins | None | SpaceBay (free) 1.0.0 or newer, installed and active |
| Database | The MySQL or MariaDB version your WordPress needs | The same |
| Permalinks | Any. Pretty permalinks give the community its own address such as /community/. | The same |

SpaceBay Pro is an add-on. If the free plugin is missing or too old, Pro shows a notice asking you to install or update SpaceBay.

Voice and video calls in Pro also need your site to use HTTPS.

See [Compatibility](/spacebay/others/compatibility/) for the themes, plugins and languages SpaceBay was tested with.

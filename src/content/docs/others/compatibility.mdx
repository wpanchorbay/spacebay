## Themes and layout

In **Settings → Appearance**, **Layout** can be **Full page**, which shows the community as a full-screen app, or **Inside your theme**, which places it between your theme header and footer. You can override the layout files: see [Template overrides](/spacebay/developers/template-overrides/).

## Multisite

- SpaceBay was tested on single sites and on multisite (network activation and sub-sites).
- Signing up only works when the network administrator allows new accounts (**Network Admin → Settings → Allow new registrations**).
- The two-factor policy is set per site. Someone who logs in on another site of the network where no code is required is logged in on every site, so use the same policy on each site.
- Deleting the plugin with **Delete all SpaceBay data when the plugin is deleted** on removes the data and images from every site in a network.

## Right-to-left languages and translation

The portal supports right-to-left languages and was tested in Arabic. SpaceBay is translation ready: see [Translation](/spacebay/developers/translation-and-building/).

## Page-cache plugins

SpaceBay marks portal pages as not cacheable (`DONOTCACHEPAGE` and no-cache headers), so members always see their own data.

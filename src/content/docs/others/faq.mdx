## Is SpaceBay free?

Yes. SpaceBay is free on WordPress.org. SpaceBay Pro is a separate paid add-on. See [Free and Pro](/spacebay/pro/overview/).

## Do I need the free plugin to use Pro?

Yes. SpaceBay Pro is an add-on. It needs SpaceBay installed and active, and WordPress 6.5 or newer. See [Requirements](/spacebay/getting-started/requirements/).

## Does Pro have a licence key?

No. You install the Pro zip and activate it like any plugin. See [Licence and activation](/spacebay/pro/licence-and-activation/).

## Where do members use the community?

On the community pages, which SpaceBay adds to your site. They work on phones and desktops, in light and dark mode. See [The community portal](/spacebay/user-guide/community-portal/).

## Can I use SpaceBay inside my theme?

Yes. In **Settings → Appearance**, set **Layout** to **Inside your theme**. See [Compatibility](/spacebay/others/compatibility/).

## Can members sell things?

With SpaceBay Pro, members can open a shop and list products that link to their own store. SpaceBay never takes payments. See [Member shops](/spacebay/pro/member-shops/).

## Can people log in with Google or Facebook?

Yes. See [Log in with Google or Facebook](/spacebay/user-guide/social-login/).

## Does SpaceBay work on multisite and in right-to-left languages?

Yes. It was tested on multisite and in Arabic. See [Compatibility](/spacebay/others/compatibility/).

## Can I export or erase a member's data?

Yes, with the WordPress privacy tools. See [Privacy and personal data](/spacebay/user-guide/privacy-and-gdpr/).

## How do I move my community to another site?

Since 1.2.0. On the old site open **SpaceBay → Import and export**, choose **Everything** and start the export. Download the file, then open the same screen on the new site, upload the file and look at the preview. When you start the import in **New** mode on an empty community, SpaceBay keeps the IDs of spaces, posts and events where it can and adds redirects from the old addresses. **Merge** adds the file to a community that already has content. **Replace** empties the community first, after saving a safety export. Every import shows a preview before it writes anything, and a Merge or New import can be undone from the same screen. See [Import and export](/spacebay/user-guide/import-and-export/).

## What is not moved?

Password hashes, two-factor secrets, login history, notifications and Pro calls are never in a file. Members get a new random password and use **Forgot your password?** to choose one, and members who used two-factor login set it up again. WordPress pages, the WordPress media library and the data of other plugins are not moved. Private messages are included only if you choose them in an **Everything** export. Accounts that already exist on the new site are matched by email address and are not changed.

## Do export files contain passwords or keys?

No passwords. Sign-in keys and secrets (Google, Facebook, the call relay) are left out unless you tick **Sign-in secrets**. A file made with that option has `-with-secrets` in its name. Keep it as private as a password. Any export holds email addresses, and an **Everything** export can hold private messages, so store the file safely. Files on the site are kept for 7 days by default and are deleted after that.

## Can I import a big community?

Yes. The upload limit is 2 GB by default. Imports run in small steps, so they do not hit the PHP time limit, and you can also use WP-CLI (`wp spacebay export` and `wp spacebay import`). A community with 5,000 or more members should run on a VPS or on a host with an object cache. Cheap shared hosting is likely to be slow or to stop the import. See [Large communities and speed](/spacebay/others/large-communities-and-speed/#big-exports-and-imports).

## Why can members not log in on the www address?

Since 1.1.2, the login, sign-up and Pro code forms only accept requests from your own site address. If members also reach the site through a `www.` or non-`www` version, a portal on a subdomain, or `http` behind a proxy that serves `https`, add that address with the WordPress `allowed_http_origins` filter. See [Security and limits](/spacebay/user-guide/security-and-limits/).

## What happens to my data if I delete the plugin?

Nothing, unless **Delete all data when the plugin is deleted** is on. See [Updates and uninstall](/spacebay/others/updates-and-uninstall/).

## How do I add demo content?

Use WP-CLI: `wp spacebay demo`. See [WP-CLI](/spacebay/developers/wp-cli/).

## Where can I get help?

- **SpaceBay (free):** ask in the [SpaceBay support forum on WordPress.org](https://wordpress.org/support/plugin/spacebay/).
- **SpaceBay Pro:** get help at [wpanchorbay.com](https://wpanchorbay.com/plugins/spacebay/).
- **Bought on CodeCanyon:** you can also use the Support tab on the CodeCanyon item page.

Please include your WordPress version, PHP version, the SpaceBay (and Pro) version and the steps that cause the issue. The latest documentation is at [docs.wpanchorbay.com/spacebay](https://docs.wpanchorbay.com/spacebay/).

---
title: "Custom profile fields"
description: "Add up to 20 extra profile fields such as Company, Country or Skills."
---

Add up to 20 extra profile fields in **SpaceBay → Members**, such as Company, Country or Skills. Each field is optional for members.

<img src="/spacebay/assets/screenshots/admin-profile-fields.png" alt="The Profile fields screen with a Company text field and a Role choice list" width="1440" height="1186" data-lightbox="true" />

*SpaceBay → Members → Profile fields.*

| Type | Members see |
| --- | --- |
| Short text | A one-line text box, up to 200 characters. |
| Long text | A text area, up to 1000 characters. |
| Link | A web address, shown as a link on the profile. |
| Choice list | A drop-down with the choices you enter, one per line. |

Removing a field hides it everywhere. Answers members already gave are kept, so adding the field back with the same name brings them back.

Without Pro, custom fields are not shown on profiles or the signup form, and the **Members** admin page shows only [Community moderators](/spacebay/user-guide/member-approval-and-moderators/#community-moderators). The fields and answers are kept.

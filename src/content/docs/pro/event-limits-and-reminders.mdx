## Place limits <span class="sb-badge sb-badge--pro">Pro</span>

:::tip[SpaceBay Pro]
This feature is part of SpaceBay Pro. See [Licence and activation](/spacebay/pro/licence-and-activation/).
:::

With Pro, an event can have a number of places. The event shows how many places are left, and when all places are taken the event is full: members can no longer answer going, but can still answer maybe. In an event with a place limit, the online link is shown only to members who answered going and to the people who manage the event.

## Reminders <span class="sb-badge sb-badge--pro">Pro</span>

:::tip[SpaceBay Pro]
This feature is part of SpaceBay Pro. See [Licence and activation](/spacebay/pro/licence-and-activation/).
:::

With Pro, members who answered going or maybe get a reminder before an event starts. Choose 1 hour, 3 hours, 1 day, 2 days or 1 week, or no reminders, under **Settings → Events** (24 hours by default). Reminders are sent by WP-Cron once an hour. On sites with little traffic, set up a real cron job for `wp-cron.php`.

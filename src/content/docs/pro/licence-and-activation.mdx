:::note
SpaceBay Pro has **no licence key** to enter. Install the zip and activate the plugin.
:::

## Getting Pro

Buy SpaceBay Pro at [wpanchorbay.com/spacebay-pro](https://wpanchorbay.com/spacebay-pro/) and download **spacebay-pro.zip** from your account. Pro is an add-on: it needs the free SpaceBay plugin installed and active, and WordPress 6.5 or newer. Pro has no licence key. SpaceBay is also sold on CodeCanyon as a bundle with both plugins.

## Install and activate

1. Install and activate the free SpaceBay plugin first.
2. Download **spacebay-pro.zip** from your wpanchorbay.com account.
3. Go to **Plugins → Add New Plugin → Upload Plugin**, choose the zip, click **Install Now**, then **Activate**.

Bought on CodeCanyon? Both zips are in your download. See [Installation](/spacebay/getting-started/installation/).

## Updates

Pro has no licence check and no updater of its own yet, so WordPress does not offer Pro updates on its own (CodeCanyon buyers can use Envato Market, see below). The plugin header points at wpanchorbay.com/spacebay-pro, which also keeps WordPress.org from offering updates for it. To update it:

1. Download the new **spacebay-pro.zip** from your wpanchorbay.com account.
2. Go to **Plugins → Add New Plugin → Upload Plugin**, choose the zip and click **Install Now**.
3. Confirm **Replace current with uploaded**.

## CodeCanyon updates

CodeCanyon buyers can keep using the free Envato Market plugin for updates:

1. Download and install the Envato Market plugin from [envato.com/lp/market-plugin](https://www.envato.com/lp/market-plugin/).
2. Create a personal token at [build.envato.com/create-token](https://build.envato.com/create-token/) with the default permissions.
3. Paste the token in **Envato Market** in your WordPress admin and save.
4. New versions now appear on **Dashboard → Updates**.

You can also download the latest zips from your CodeCanyon Downloads page and upload each one with **Replace current with uploaded**.

Your community data is kept during updates. SpaceBay Pro 1.0.0 needs SpaceBay 1.0.0 or newer.

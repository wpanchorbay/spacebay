---
title: "Appearance settings"
description: "Layout, default colour mode, logo, community icon, sidebar heading, brand colour and space icon colours."
---

Open **SpaceBay → Settings** and choose the **Appearance** section in the left column. Select **Save changes** at the top right when you are done.

| Setting | What it does |
| --- | --- |
| Layout | **Full page** shows the community as a full-screen app. **Inside your theme** places it between your theme header and footer. |
| Default colour mode | Follow device, Light or Dark. Members can switch with the moon/sun button. |
| Logo | Choose an image from the media library. It is shown 32 pixels high in the top bar and at the top of emails. In dark mode the logo sits on a white plate so dark text stays readable. |
| Community icon <span class="sb-badge sb-badge--since">Since 1.1.0</span> | Choose a square image from the media library, at least 512 × 512 pixels. It is shown next to the community name and used as the browser tab icon (favicon) of your community. Without one, your site icon is used. |
| Heading layout <span class="sb-badge sb-badge--since">Since 1.1.0</span> | How the top of the community sidebar looks. Choose **Automatic** (the logo, or the icon and the name when there is no logo), **Icon + name**, **Logo + name**, **Icon on top, name below**, **Logo on top, name below**, **Icon + logo on top, name below**, **Name only**, **Icon only** or **Logo only**. A live preview shows exactly what members will see. A layout that needs a logo or an icon you have not added shows the name or the first letter of your community name until you add it. |
| Show the community name | Shown with the **Automatic** heading layout only. Turn off when your logo already contains the name. |
| Brand colour | Colour of buttons, links, highlights, space icons and email buttons. Choose one of 11 ready-made colours (SpaceBay blue, Green, Teal, Blue, Indigo, Violet, Pink, Red, Orange, Amber, Slate) or any custom colour; the preview shows how it looks. Very light colours are darkened slightly so white text on buttons stays readable. Light tints for dark mode are worked out automatically. The default is SpaceBay blue (`#3f22ff`). |
| Space icon colours | **One colour** shows every space icon in the brand colour. **Each space** uses the colour chosen for each space, and the space form then shows colour swatches. |
